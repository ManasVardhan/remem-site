# re-mem.com

The website for [reMem](https://www.npmjs.com/package/remem-kernel), a memory
kernel for agents: an append-only ledger, a belief layer derived from it, and
new information that supersedes old without deleting it.

One self-contained `index.html`. No build step, no dependencies. Fonts come
from Google Fonts; everything else is inline.

Served by GitHub Pages at <https://re-mem.com>.

Kernel source and issues live in the main repository.
